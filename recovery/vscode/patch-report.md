## Method

1. upstream-index.json: sha256 + size + type for all 8,444 files under src/vs.
2. nls-map.json: each of the 1,150 nls paths resolved to src/<path>.ts|.tsx|.js; absent paths get same-basename upstream candidates.
3. Module bounds: the inventory segment runs to the next wrapper and includes hoisted code of the following module. The matcher uses only the wrapper body (from the wrapper opening brace to the first newline followed by "} })"), recorded as bodyRange.
4. Evidence, in priority order: (a) nls index: Cursor bundles replace localize(key, msg) with localize(index, null) using the flat nls.messages.json order, so a module body whose numeric calls fall inside one nls module range identifies that source path; (b) import graph: wrapper init calls map to sibling module basenames via the wrapper declaration, compared to upstream import basenames; (c) literal anchors: string literals plus non-mangled property names, weighted by inverse document frequency; (d) unique basename.
5. Confidence: A = nls index match with matching basename, or dep>=0.55 and >=4 shared rare anchors, or unique basename + dep>=0.45 + >=3 anchors; B = dep>=0.3 with >=2 anchors, unique basename with >=2 anchors, or >=2 nls hits; C = basename-only candidate (reported as unresolved); unresolved = no A/B evidence.
6. Classification of matched modules: bundle body anchors are compared to the matched file. Property anchors are ignored for diffs because esbuild export wiring and TS enums synthesize them; string anchors that occur anywhere in the upstream file text are ignored (compiler-generated). 0-1 residual string anchors -> upstream-exact, otherwise upstream-modified. Files with fewer than 6 anchors -> unknown (matched but unverifiable).
7. patches/*.md and patch-evidence.json list every residual bundle-only anchor with absolute bundle char range, plus a flag for strings absent from the entire src/vs tree (strongest evidence). No intent is inferred. Patch files are named <bundle-tag>-<ordinal>-<basename>.md so each bundle module gets a unique file.

## Limitations

- Cursor strips localized messages: localize calls become numeric indices, so English UI text is not available as an anchor. localize2 messages survive and do anchor matches.
- esbuild hoists declarations outside wrapper bodies; the body bound loses code placed before the wrapper, so some modules have too few anchors to judge (reported unknown).
- Bundles are minified; class/function/variable identifiers are gone. Matching relies on string literals, property names, import edges and nls indices.
- A module can appear in several bundles (main/desktop/glass) with different minification; each bundle module is mapped independently.
- The 180 absent nls paths cover Cursor-added workbench modules only where they emit localize keys; other Cursor modules stay unresolved.
- No node_modules tree was indexed, so third-party classification is conservative (basename list + markers).
